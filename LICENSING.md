The scan engine, CLI, the free GitHub Action, tests, fixtures, public
documentation and the landing page. The public promise stands:

> The engine and the free Action stay free forever.

The Pro layer is sold as a service and developed in a private repo:
PR-bot server, RedTeam pipeline (prompts), audit/outreach tooling,
deployment configuration, Pro onboarding docs, and upcoming Pro
features (automatic re-sharpening PRs, rule editor, multi-tenant,
billing).
