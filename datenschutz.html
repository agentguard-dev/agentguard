1. Grundsatz

Diese Website verarbeitet keine personenbezogenen Daten im Sinne der DSGVO. Es gibt kein Nutzerkonto, kein Newsletter-Formular, keine Kommentarfunktion und keine Eingabe personenbezogener Daten.

2. Besuchsstatistik (GoatCounter)

Zur Reichweitenmessung setzen wir GoatCounter ein — eine datenschutzfreundliche, cookie-lose Statistik, die keine personenbezogenen Daten erhebt, keine Profile bildet und keine IP-Adressen speichert. Mehr dazu: GoatCounter & DSGVO.

3. Hosting (GitHub Pages)

Diese Website wird über GitHub Pages (GitHub, Inc.) ausgeliefert. Beim Abruf einer Seite können durch den Hoster technisch bedingte Server-Logs entstehen (z. B. IP-Adresse, User-Agent, Zeitstempel). Diese Verarbeitung erfolgt durch den Hoster im Rahmen des Hosting-Betriebs.

4. Externe Inhalte

Die Seite bindet keine externen Skripte, Styles, Fonts oder Tracking-Dienste ein — mit Ausnahme des oben genannten GoatCounter-Skripts. Links zu GitHub führen beim Anklicken zu den Datenschutzbestimmungen des jeweiligen Anbieters.

5. Deine Rechte

Da wir keine personenbezogenen Daten verarbeiten, bestehen insoweit keine Auskunfts-, Berichtigungs- oder Löschungsansprüche gegen uns. Bei Fragen erreichst du uns über das Repository: github.com/agentguard-dev/agentguard.
