AgentGuard Pro — GitHub App registrieren

Dieses Formular erstellt die GitHub App über den offiziellen Manifest-Flow. Klicke unten auf den Button — GitHub erstellt die App und zeigt dir direkt App-ID und Private Key an.

Nach dem Erstellen (App-Einstellungen): 1) unter „Webhook" die URL (öffentliche Domain + /webhook) und das Secret setzen — generiere es mit openssl rand -hex 32 und lege es nie in Dateien oder Chats ab (lokal z. B. nach ~/.config/agentguard/webhook-secret). 2) Server starten: AGENTGUARD_WEBHOOK_SECRET in der Server-Umgebung auf denselben Wert setzen.
