This website processes no personal data in the sense of the GDPR. There is no account, no newsletter form, no comment section and no input of personal data.

2. Analytics (GoatCounter)

We use GoatCounter for reach measurement — a privacy-friendly, cookie-less analytics service that collects no personal data, builds no profiles and stores no IP addresses. See GoatCounter & GDPR.

3. Hosting (GitHub Pages)

This website is delivered via GitHub Pages (GitHub, Inc.). The host may create technically required server logs (e.g. IP address, user agent, timestamp) as part of operating the service.

4. External content

The page embeds no external scripts, styles, fonts or tracking services — with the exception of the GoatCounter script named above. Links to GitHub lead to the respective provider's privacy policies.

5. Your rights

Since we process no personal data, there are no access, rectification or erasure claims against us in this respect. For questions, reach us via the repository: github.com/agentguard-dev/agentguard.
